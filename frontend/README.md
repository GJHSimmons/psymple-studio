# Psymple Studio — frontend

React + Vite + TypeScript app. See the repository root `CLAUDE.md` for project context and
`design/design_handoff_psymple_studio/` for the design spec.

```bash
npm install
npm run dev      # start the dev server
npm run test     # run the vitest suite
npm run lint     # eslint
npm run format   # prettier --write
npm run build    # typecheck + production build
```
